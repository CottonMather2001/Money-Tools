# Money Tools

Two free, private money tools that run entirely in the browser:

- **Budget tracker** (`budget-tracker.html`): import bank and card CSV exports, compare spending with a monthly or per-paycheck plan.
- **Five-year money plan** (`five-year-money-plan.html`): monthly plan by phase, loan payoff calculator, savings goals, to-do list.

Each person's data is stored only in their own browser (localStorage). Nothing is sent to a server. Not financial advice.
