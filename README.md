# Money Tools

Free, private money tools that run entirely in the browser:

- **Budget tracker** (`budget-tracker.html`): import bank and card CSV exports and compare spending with a monthly or per-paycheck plan. Each person's data is stored only in their own browser (localStorage); nothing is sent to a server.
- **Build my 5-year plan with Claude** (on the home page): opens Claude with a prompt that interviews you and builds a personalized five-year plan.

Not financial advice.
